# GRADE CURRICULAR — ProfessorDash 2026

> Plano curricular completo das 3 turmas seed do ProfessorDash.
> Público: alunos 14–18 anos, ensino técnico integrado ao médio, SEED-PR.
> Carga horária: 2 aulas/semana de 50 min cada.

---

## Turma 1 — Programação Front-End (PFE-2A-M-2026)

**Progressão pedagógica:** do HTML básico ao deployment de uma SPA completa.

| # | Aula | Modo | Seções | Objetivos |
|---|------|------|--------|-----------|
| 01 | Internet e o funcionamento da Web | Conceitual | 5 | Compreender como a internet funciona, o modelo cliente-servidor, HTTP/HTTPS, DNS e o papel do navegador |
| 02 | HTML — Estrutura e primeiras tags | Prático | 6 | Criar a primeira página HTML com estrutura básica, headings, parágrafos e listas |
| 03 | HTML Semântico e boas práticas | Conceitual | 5 | Diferenciar HTML semântico de não-semântico, aplicar tags HTML5 e entender impacto em acessibilidade e SEO |
| 04 | CSS — Seletores e estilização básica | Prático | 6 | Aplicar CSS inline, interno e externo; usar seletores de tag, classe e ID |
| 05 | CSS Flexbox — Layouts flexíveis | Prático | 6 | Construir layouts responsivos com Flexbox: direção, alinhamento, wrapping e distribuição |
| 06 | CSS Grid — Layouts bidimensionais | Prático | 6 | Criar layouts complexos com Grid: template areas, fr, gap e responsividade |
| 07 | JavaScript — Variáveis, tipos e operadores | Conceitual | 5 | Compreender os tipos primitivos do JS, declaração de variáveis (var, let, const) e operadores básicos |
| 08 | JavaScript — Controle de fluxo e funções | Prático | 6 | Usar estruturas condicionais, loops e declarar funções com parâmetros e retorno |
| 09 | DOM — Manipulando a página com JavaScript | Prático | 6 | Selecionar e modificar elementos do DOM, criar elementos dinâmicos e responder a eventos |
| 10 | Formulários HTML e validação | Prático | 6 | Construir formulários com validação nativa e customizada em JS, capturar dados com FormData |
| 11 | LocalStorage e persistência no navegador | Conceitual | 5 | Persistir dados no navegador com localStorage e sessionStorage, serializar com JSON |
| 12 | Projeto final — Mini e-commerce front-end | Prático | 7 | Integrar HTML, CSS e JS em um projeto completo com carrinho de compras e dados persistentes |

## Turma 2 — Programação Back-End (PBE-2A-M-2026)

**Progressão pedagógica:** do raciocínio lógico à construção de uma API REST com Django.

| # | Aula | Modo | Seções | Objetivos |
|---|------|------|--------|-----------|
| 01 | Lógica de Programação com Python | Conceitual | 5 | Compreender algoritmos, variáveis, tipos de dados e entrada/saída em Python |
| 02 | Estruturas condicionais e repetição | Prático | 6 | Aplicar if/elif/else, while e for na resolução de problemas sequenciais |
| 03 | Listas, tuplas e dicionários | Conceitual | 5 | Dominar estruturas de dados nativas do Python e suas operações principais |
| 04 | Funções — modularização e reuso | Prático | 6 | Declarar funções com parâmetros, retorno e escopo; entender docstrings |
| 05 | Manipulação de arquivos e exceções | Prático | 6 | Ler/escrever arquivos CSV e JSON, tratar erros com try/except |
| 06 | Introdução à orientação a objetos | Conceitual | 5 | Compreender classes, objetos, atributos, métodos e encapsulamento |
| 07 | Herança, polimorfismo e duck typing | Prático | 6 | Aplicar herança entre classes, sobrescrita de métodos e duck typing |
| 08 | Introdução ao Django — Models e Admin | Prático | 6 | Criar um projeto Django, definir models e registrar no admin |
| 09 | Django — Views, URLs e Templates | Prático | 6 | Construir páginas dinâmicas com views baseadas em classe e templates Django |
| 10 | Django — Forms e manipulação de dados | Prático | 6 | Criar formulários com ModelForm, validar dados e persistir no banco |
| 11 | Django REST Framework — Construindo APIs | Prático | 7 | Expor dados via API REST com serializers, ViewSets e routers |
| 12 | Projeto final — API de catálogo de filmes | Prático | 7 | Integrar models, views, serializers e autenticação em uma API completa |

## Turma 3 — Banco de Dados (BD-2A-M-2026)

**Progressão pedagógica:** da teoria relacional à modelagem e consultas complexas.

| # | Aula | Modo | Seções | Objetivos |
|---|------|------|--------|-----------|
| 01 | Conceitos fundamentais de banco de dados | Conceitual | 5 | Compreender o que é um banco de dados, SGBD, modelo relacional e a diferença entre dado e informação |
| 02 | Modelagem conceitual — DER e entidades | Conceitual | 5 | Construir diagramas entidade-relacionamento identificando entidades, atributos e relacionamentos |
| 03 | Modelagem lógica — tabelas, chaves e normalização | Prático | 6 | Transformar DER em esquema lógico, definir chaves primárias/estrangeiras e aplicar 1FN/2FN/3FN |
| 04 | SQL — DDL: CREATE, ALTER e DROP | Prático | 6 | Criar e modificar tabelas com SQL DDL, definir constraints e tipos de dados |
| 05 | SQL — DML: INSERT, UPDATE e DELETE | Prático | 6 | Inserir, atualizar e remover registros com SQL DML, compreender transações |
| 06 | SQL — SELECT, WHERE e ordenação | Prático | 6 | Consultar dados com SELECT, filtrar com WHERE, ordenar com ORDER BY e limitar com LIMIT |
| 07 | SQL — JOINs e consultas multi-tabela | Conceitual | 5 | Combinar tabelas com INNER JOIN, LEFT JOIN e RIGHT JOIN para consultas relacionais |
| 08 | SQL — Funções de agregação e GROUP BY | Prático | 6 | Agrupar dados com GROUP BY, usar COUNT, SUM, AVG, MAX, MIN e HAVING |
| 09 | SQL — Subconsultas e views | Conceitual | 5 | Escrever subconsultas aninhadas e criar views para simplificar consultas complexas |
| 10 | Índices, performance e boas práticas | Conceitual | 5 | Compreender índices, plano de execução e estratégias para otimizar consultas |
| 11 | Integridade referencial e triggers | Prático | 6 | Garantir consistência com chaves estrangeiras, triggers e regras de negócio no banco |
| 12 | Projeto final — Modelagem de sistema escolar | Prático | 7 | Modelar e implementar o banco de dados completo de um sistema escolar do DER ao SQL |
